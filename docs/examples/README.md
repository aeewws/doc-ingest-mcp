# Example bundles

These directories are generated from the bundled smoke fixtures with `--backend fake`.

- `sample-pdf/` demonstrates a short PDF with headings, paragraphs, and a generated table.
- `contract-docx/` demonstrates a DOCX with the same bundle contract.

Each bundle contains the exact files this project promises to agents:

- `manifest.json`
- `document.md`
- `chunks.jsonl`
- `assets/`
- `tables/`
